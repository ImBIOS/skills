# Design

Skills for generating product UI and brand assets as self-contained files.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[landing-page](./landing-page/SKILL.md)**: Polished hero landing page with a working product demo block.
- **[saas-dashboard](./saas-dashboard/SKILL.md)**: Dense dashboard screen with KPIs, SVG chart, and sortable table.
- **[bento-features](./bento-features/SKILL.md)**: Bento grid where each cell is a working miniature of one feature.
- **[saas-logo](./saas-logo/SKILL.md)**: Flat geometric logo concepts in SVG, exported as mark plus app-icon PNGs.
- **[low-res-mockup](./low-res-mockup/SKILL.md)**: Skeleton wireframe with placeholder blocks instead of copy.
