# landing-page

## What it does

Turns a product paragraph into a finished hero landing page: one self-contained HTML file with headline, CTAs, proof elements, and a working visual demo of the product interface built from divs, plus supporting sections. Opens directly in a browser with no build step.

## When to reach for it

Reach for it when asked to build, mock, or prototype a SaaS homepage, hero section, or launch page. Typical triggers: "landing page for X", "hero mock", "prototype the homepage", "marketing page with a product demo".

## Common questions

**What do you need from me?** A paragraph describing the product, or its name plus features. Color scheme is optional; the skill picks one and says so.

**Is this production code?** No. It is a front-end mock for design review or pasting into a builder. No framework, backend, or analytics.

**How is the demo interactive?** Small inline JS only: tabs, toggles, animated counters, filterable rows. Enough to feel like the product, not a screenshot.

**How does this relate to the Paralect catalog?** Functional scope matches their landing page skill (https://www.paralect.com/skills/landing-page). This is an original implementation, not affiliated, with no shared text or code.

## It's working if

The HTML file opens with no build, hero plus CTA fit the first viewport, the demo block responds to at least one interaction, layout holds at 390px width, and there are no console errors.
