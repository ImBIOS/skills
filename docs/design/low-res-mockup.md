# low-res-mockup

## What it does

Turns a few words ("settings page", "checkout step 2") into a skeleton wireframe: gray bars for text, boxes for media, labeled outlines for components, numbered callouts for open questions. Structure only, never finished design.

## When to reach for it

Reach for it when exploring layout or hierarchy before copy and visuals exist. Typical triggers: "wireframe for X", "rough mockup", "layout sketch in HTML", "low fi mock".

## Common questions

**Why no real text?** Real copy makes reviewers critique words instead of structure. Skeletons keep the conversation on layout.

**One file only?** Yes, self-contained HTML with desktop and phone frames stacked when both matter.

**How does this relate to the Paralect catalog?** Functional scope matches their low res mockup skill (https://www.paralect.com/skills/low-res-mockup). This is an original implementation, not affiliated, with no shared text or code.

## It's working if

The file shows regions and hierarchy with zero real sentences, every component is labeled, open questions are numbered callouts, and no one could mistake it for the final page.
