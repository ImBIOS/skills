# bento-features

## What it does

Turns a feature list into a bento grid where each cell is a working miniature of one feature (toggles, mini charts, fake rows, animated counters) with a short caption. One self-contained HTML file, no build step.

## When to reach for it

Reach for it for feature overviews, bento grids, or features sections where tiles should demonstrate rather than describe. Typical triggers: "bento grid for X", "features section with live mocks", "show all features at a glance".

## Common questions

**How many features fit?** Six is ideal (hero plus wide plus small cells). More get grouped, fewer get split by aspect.

**Can a cell be text only?** No. Every cell carries a working miniature plus a one line caption.

**How does this relate to the Paralect catalog?** Functional scope matches their bento features skill (https://www.paralect.com/skills/bento-features). This is an original implementation, not affiliated, with no shared text or code.

## It's working if

Every cell shows a mockup that responds to at least one interaction, cells share one design language, the grid holds at desktop and phone widths, and motion respects reduced motion settings.
