# og-image-animated

## What it does

Turns the approved static share card into a 2 to 2.5 second animated reveal (headline in, UI rising into place, clean loop hold) delivered as MP4 plus GIF with a poster frame.

## When to reach for it

Reach for it when asked to animate a share card or produce a looping social preview. Typical triggers: "animated og image", "animate the share card", "OG video", "looping preview clip".

## Common questions

**Do I need the static card first?** Yes. The animation reuses its composition so both versions match. Run `og-image` first when none exists.

**How long is the clip?** About 2.4 seconds by default, never over 3. Custom timing only on request.

**How does this relate to the Paralect catalog?** Functional scope matches their animated OG image skill (https://www.paralect.com/skills/og-image-animated). This is an original implementation, not affiliated, with no shared text or code.

## It's working if

The clip runs under 3s, the end frame matches the static card, the loop restart is invisible, and MP4 plus GIF plus poster are all delivered with sane file sizes.
