# article-image

## What it does

Turns the paragraph an image runs with into a finished blog illustration in one of eight house styles (ink sketch, retro comic, isometric, blueprint, color block, grainy isometric, gradient grain, desk scene). Web-ready file plus alt text, named for the post.

## When to reach for it

Reach for it when illustrating a blog post, changelog entry, or essay. Typical triggers: "blog post image", "article header image", "illustrate this paragraph", "cover image in blueprint style".

## Common questions

**Which style when none is given?** The skill picks from the paragraph mood: technical leans blueprint or isometric, opinion leans ink or comic, product news leans desk scene or color block. One style per post for consistency.

**Can the image contain text?** No. No words, logos, or UI screenshots inside the illustration.

**How does this relate to the Paralect catalog?** Functional scope matches their blog post image skill including its eight style variants (https://www.paralect.com/skills/article-image). This is an original implementation, not affiliated, with no shared text or code.

## It's working if

The image reflects the paragraph's concrete nouns, matches the house style, stays clean at thumbnail size, ships under 500KB with descriptive filename and alt text.
